Gateway benchmark · S0 / S1 / S2, real gateway.c

    

      

        
        
      

      
The same gateway (src/gateway/gateway.c) as an admission controller in front of a permissive ECU, versus a stateless firewall, on the same attack corpus. A stateless filter cannot tell an authorized reset from an unauthorized one; the gateway reconstructs the security state and blocks every unauthorized reset while breaking no legitimate flow.
